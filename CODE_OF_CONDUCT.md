# Code of Conduct

## Our standard

MTScan contributors and maintainers are expected to keep project interactions professional, technical, and respectful.

Acceptable participation includes:

- Critiquing code, documentation, and security decisions rather than attacking people.
- Providing reproducible evidence for technical claims.
- Respecting different experience levels and asking for clarification without ridicule.
- Keeping security research within authorized and legal boundaries.
- Protecting private target data, credentials, and vulnerability reports.

Unacceptable behavior includes harassment, threats, discriminatory conduct, deliberate disruption, publishing another person's private information, or pressuring contributors to disclose sensitive vulnerability details publicly.

## Security discussions

Do not use public project discussions to disclose an unpatched vulnerability in MTScan, real credentials, private scan data, or sensitive third-party target information. Follow [SECURITY.md](SECURITY.md).

## Enforcement

The repository maintainer may edit or remove comments, close discussions, reject contributions, or restrict participation when behavior violates this policy or creates a security/privacy risk.

Reports about conduct should be directed to the repository maintainer through an appropriate private GitHub channel when possible. Do not include unrelated sensitive security data in conduct reports.

## Scope

This code of conduct applies to project repositories, issues, pull requests, reviews, documentation contributions, and other official MTScan project spaces.
