MTScan command reference

Supported interfaces:
- python3 mtscan.py
- python3 src/workflow.py

There is no app interface yet.

Run one tool:
- python3 src/workflow.py -naabu -host example.com --top-ports 100
- python3 src/workflow.py -httpx -host example.com --title --status-code --tech-detect
- python3 src/workflow.py -nuclei -host https://example.com --severity critical,high

Run all tools together:
- python3 src/workflow.py --all -host example.com --top-ports 100 --save-output

Windows command-construction checks:
- python src/workflow.py --dry-run --all -host example.com --top-ports 100 --save-output

Naabu options:
- -host, --host: target host
- -p, --ports: ports, for example 80,443 or 1-1000
- --top-ports: number of common ports to scan
- --exclude-ports: ports to skip
- --threads: concurrency
- --rate: packets per second
- --scan-type: connect or syn
- --naabu-timeout: timeout
- --naabu-retries: retries

HTTPX options:
- --title: show page titles
- --status-code: show status codes
- --tech-detect: detect technologies
- --web-server: show web server header
- --follow-redirects: follow redirects
- --content-length: show content length
- --response-time: show response time
- --httpx-timeout: timeout
- --httpx-threads: threads
- --headers: comma-separated custom headers
- --user-agent: custom User-Agent

Nuclei options:
- -t, --templates: template path or template selector
- --template-path: template path
- --tags: template tags
- --severity: severity filter
- --exclude-tags: excluded tags
- --exclude-templates: excluded templates
- --concurrency: template concurrency
- --nuclei-rate-limit: request rate limit
- --nuclei-timeout: request timeout
- --nuclei-retries: retries
- --custom-headers: comma-separated custom headers
- --vars: template variables
- --store-resp: store matched responses
- --no-interactsh: disable Interactsh

Output options:
- --save-output: save tool output files
- --json-output: save JSON/JSONL where supported
- -o, --output-dir: choose output directory
- --tool-silent: reduce tool output

Safety:
- Use only targets you own or are authorized to test.
