## Why These Licenses

Apache-2.0, MIT, and BSD-3-Clause are widely used, institutionally recognized,
OSI-approved open-source licenses. This gives users a clear permissive licensing
path while preserving the author's copyright ownership.

Apache-2.0 is useful when users want explicit patent language. MIT and BSD
3-Clause are simple permissive options that are familiar across open-source
ecosystems.
